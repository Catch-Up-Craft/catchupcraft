O que mudou no Minecraft desde a tua versão?

O Catch Up Craft é um changelog do Minecraft que funciona entre quaisquer duas versões. Escolhes a versão em que o teu mundo está e a versão que queres jogar, e vês todas as atualizações pelo meio: mobs, blocos, itens, biomas e mudanças de jogabilidade, mais os avisos sobre o que pode estragar farms, mods ou redstone. Cobre a Java Edition e a Bedrock Edition, da 1.0 à 26.3 e a 26.4, que ainda está em testes.

A app pode ser mudada para português nas Definições; os resumos das mudanças dentro da app estão em inglês. As páginas de cada atualização neste site estão em português.

Perguntas frequentes

O que é o Catch Up Craft?

O Catch Up Craft é uma app web que mostra tudo o que mudou no Minecraft entre duas versões. Escolhes a versão em que o teu mundo está e a versão que queres jogar, e a app lista todas as atualizações pelo meio, com as grandes mudanças primeiro. Cobre a Java Edition e a Bedrock Edition.

Qual é a versão mais recente do Minecraft?

A versão mais recente da Java Edition é a 26.3 (Wilderness Bound), lançada a 15 de setembro de 2026. A da Bedrock Edition é a 26.60, lançada a 27 de outubro de 2026. A próxima atualização, a 26.4, está em testes.

O que mudou no Minecraft desde a 1.16?

Desde a Nether Update (1.16, junho de 2020), a Java Edition teve mais 15 grandes atualizações, incluindo Caves & Cliffs (1.17 e 1.18), The Wild Update (1.19), Trails & Tales (1.20), Tricky Trials (1.21) e os game drops de 2025–2026 até à 26.3 Wilderness Bound. Escolhe a 1.16 na app para ver todas as mudanças.

Porque é que as versões do Minecraft agora são 26.1, 26.2 e assim por diante?

Em 2026 o Minecraft passou a usar números baseados no ano: ano.drop. A Java 26.1 é o primeiro game drop de 2026, e a 1.21.11 foi a última versão Java com a numeração antiga 1.x. A Bedrock também usa números baseados no ano, mas são diferentes: a Java 26.3 corresponde à Bedrock 26.50.

Que versão Bedrock corresponde a que versão Java?

As grandes atualizações chegam às duas edições com números diferentes. Por exemplo, Tricky Trials é a Java 1.21 e a Bedrock 1.21.0, The Copper Age é a Java 1.21.9 e a Bedrock 1.21.111, e Wilderness Bound é a Java 26.3 e a Bedrock 26.50. A página do histórico tem todos os pares.

É seguro abrir um mundo antigo do Minecraft numa versão mais recente?

Normalmente sim, mas faz primeiro uma cópia de segurança da pasta do mundo, porque depois de o mundo ser convertido não dá para voltar a uma versão antiga. Atualiza ou remove mods, pacotes de recursos e pacotes de dados que não suportem a versão nova, e verifica as farms e as máquinas de redstone, porque algumas mecânicas mudam entre versões. O Catch Up Craft mostra estes avisos para o teu intervalo de versões.

O Catch Up Craft é um site oficial do Minecraft?

Não. O Catch Up Craft é uma ferramenta feita por fãs. Não é um produto oficial do Minecraft e não é aprovado pela Mojang ou pela Microsoft nem está associado a elas.

Os resumos são descrições curtas escritas para o Catch Up Craft. Para todos os detalhes, segue as ligações para a Minecraft Wiki (uma wiki da comunidade, que não faz parte deste site), que tem ligações para os artigos da própria Mojang.
