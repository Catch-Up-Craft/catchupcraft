What changed in Minecraft since your version?

Catch Up Craft is a Minecraft changelog that works between any two versions. Pick the version your world is on and the version you want to play, and you get every Minecraft update in between: new mobs, blocks, items, biomes and gameplay changes, plus the heads-up changes that can break farms, mods or redstone. It covers Java Edition and Bedrock Edition, from 1.0 to 26.3 and the upcoming 26.4.

Latest release: Java 26.3 Wilderness Bound (September 15, 2026) · Bedrock 26.60 (October 27, 2026).

Questions

What is Catch Up Craft?

Catch Up Craft is a web app that shows everything that changed in Minecraft between two versions. You pick the version your world is on and the version you want to play, and it lists every update in between, with the big changes first. It covers Java Edition and Bedrock Edition.

What is the latest version of Minecraft?

The latest Java Edition release is 26.3 (Wilderness Bound), released on September 15, 2026. The latest Bedrock Edition release is 26.60, released on October 27, 2026. The next update, 26.4, is in testing.

What has changed in Minecraft since 1.16?

Since the Nether Update (1.16, June 2020) Java Edition has had 15 more big updates, including Caves & Cliffs (1.17 and 1.18), The Wild Update (1.19), Trails & Tales (1.20), Tricky Trials (1.21) and the 2025–2026 game drops up to 26.3 Wilderness Bound. Choose 1.16 in the app to see every change.

Why are Minecraft versions now numbered 26.1, 26.2 and so on?

In 2026 Minecraft switched to year-based version numbers: year.drop. Java 26.1 is the first game drop of 2026, and 1.21.11 was the last Java version with the old 1.x numbering. Bedrock also uses year-based numbers, but they differ: Java 26.3 matches Bedrock 26.50.

Which Bedrock version matches which Java version?

The big updates arrive on both editions with different version numbers. For example, Tricky Trials is Java 1.21 and Bedrock 1.21.0, The Copper Age is Java 1.21.9 and Bedrock 1.21.111, and Wilderness Bound is Java 26.3 and Bedrock 26.50. The update history page lists every pair.

Is it safe to open an old Minecraft world in a newer version?

Usually yes, but back up the world folder first, because you can't go back to an older version once the world is converted. Update or remove mods, resource packs and data packs that don't support the new version, and check farms and redstone machines, since some mechanics change between versions. Catch Up Craft lists these heads-up changes for your range.

Is Catch Up Craft an official Minecraft site?

No. Catch Up Craft is a fan-made tool. It is not an official Minecraft product and is not approved by or associated with Mojang or Microsoft.

The summaries in this app are short descriptions written for Catch Up Craft. For full details, every version links to its page on the Minecraft Wiki (a community wiki, not part of this app), which links to Mojang's own articles. Built-in data is current to November 2026; when you're online, new Java version numbers are added from Mojang's public version list. Bedrock versions before 1.17 show only the main updates.
